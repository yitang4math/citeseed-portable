# 找出"真正引发该研究"的 1-3 篇核心参考文献

目标输入：一篇论文的 PDF（+ 可选参考文献列表）。
目标输出：按启发强度排序的 1-3 篇参考文献，每篇给出**作者/题名/年份/出处**、**逐字原文证据（含章节页码）**、**对本文的具体影响**，以及**把握程度**；证据不足时明确说明缺什么。

---

## 一、先说结论：没有现成工具能直接做这件事

这件事需要四个能力串联，**现有工具每个只覆盖其中一段**：

| 环节 | 代表方案 | 能做到 | 为什么不够 |
|---|---|---|---|
| ① 抽取引用上下文 | GROBID / Docling / Marker | 从 PDF 拿正文、参考文献、引用标记对齐 | 只解决"引用在哪一句"，不判断作用 |
| ② 引用意图分类 | **SciCite**（allenai, 2019） | background / method / result 三类 | **只有 3 类**，没有"动机""指出局限""揭示空白" |
| ② 引用意图分类 | **MultiCite**（allenai, NAACL 2022） | 8 类，含 **Motivation / Extends / Differences / Future Work** | 目前**唯一**把"动机"单独列类的体系；但只覆盖计算语言学，且只发数据集、未发可直接用的权重 |
| ③ 判断"重不重要" | **Valenzuela et al. 2015**（AAAI, *Identifying Meaningful Citations*） | important vs. incidental 引文 | 精度只有 **P=0.65 @ R=0.90**；后续复现研究（arXiv:1707.04207）发现其 12 个特征中 **3 个不可复现、多个不具预测力** |
| ③ 领域级溯源 | RPYS / CRExplorer（marX 等） | 找整个领域的"历史根源"文献 | 是**领域级**方法，需要上千篇文献的引文集合，**不能针对单篇** |
| ④ 上下游追踪 | ResearchRabbit / Litmaps / Connected Papers | 谁引谁、时间线、聚类 | 完全不判断"启发作用"，且闭源 |
| ④ 端到端 | 长上下文 LLM 直读 PDF | 可以直接给出判断 | 无证据锚定 → 幻觉；长文上下文丢失；不可审计 |
| ④ 端到端 | **PaperQA2**（FutureHouse / Edison，`paper-qa>=5`） | agentic RAG、引文遍历、强制可追溯引文 | 面向"跨文献问答"，不是"分析单篇的引用动机"；需 LLM API，默认解析器依赖 GROBID（要 Java/Docker） |

**结论**：最接近的三个积木是 **MultiCite 的意图体系（给定义）+ Valenzuela 的重要性框架（给排序思路）+ 长上下文 LLM（给裁决）**。本工具做的事就是把它们串起来，并额外加一条硬约束：**每条判定必须附逐字原文，否则弃权**。

---

## 二、两个决定了流程设计的经验事实

**1. 分类器不能当结论。** Valenzuela 的重要引文分类器 P=0.65，意味着三分之一的"重要引文"判定是错的。所以规则/统计只用来**把 80 篇压到 8 篇**，最终判定交给有原文证据的 LLM 或人。

**2. "动机鸿沟"（Motivation Gap）。** MultiCite 实测：**17.1% 的引用语境跨越多句**，Motivation 类引用尤其很少完整表达在带引用标记的那一句话里——因为作者常把"X 做了什么"和"但 X 做不到什么，所以我们…"分开写。

> 直接后果：只看那一句会系统性漏掉真正的动机文献。本工具的证据窗口默认是 **目标句 ±2 句**。
> 但窗口一宽就会把邻句的动机语言错记到本引用头上——实测把一本谱图论教科书误判成了"揭示研究空白"。因此线索按距离衰减：**目标句 ×1.0，±1 句 ×0.6，±2 句 ×0.3**。

## 三、流程

```bash
# 0) 准备：文本型 PDF（扫描件需先 OCR）+ 可选参考文献列表（BibTeX/RIS/txt）
# 1) 抽取：正文分句、引用上下文、参考文献条目
python citeparse.py paper.pdf --refs refs.bib --out out

# 2) 排序 + 生成证据包：把 N 篇压到 8 篇，并给出可核查的原文证据
python seedfinder.py out --top 8 --metadata

# 3) 裁决（二选一）
python seedfinder.py out --llm          # 有 LLM_API_KEY 时自动调用
#    或：把 out/seeds_prompt.md 整段粘贴给任意长上下文模型
```

产出：

| 文件 | 用途 |
|---|---|
| `seeds_ranked.csv` / `.md` | 全部参考文献的启发强度打分，**含各分量，可审计** |
| `seeds_evidence_pack.md` | 前 N 名的完整原文证据（±2 句窗口，`[>>]` 标记目标句） |
| `seeds_prompt.md` | 已注入证据的裁决提示词，可直接粘贴 |
| `seeds_llm.json` / `.md` | `--llm` 时的最终 1-3 篇结论 |

## 四、打分体系（全部可调，全部可审计）

**章节基础权重**（动机类章节高，实验章节低）

| 章节 | 权重 | 章节 | 权重 |
|---|---|---|---|
| 研究动机 | 3.3 | 方法 | 1.6 |
| 摘要 | 3.0 | 讨论 | 1.3 |
| 引言 | 2.8 | 结论 | 0.8 |
| 相关工作 | 2.0 | 实验/结果 | 0.6 |

**线索词权重**（中英双语）

| 线索 | 权重 | 含义 |
|---|---|---|
| **GAP** | +3.0 | however / remains open / fails to / little work / 然而·尚未·鲜有·局限·空白 |
| **INSPIRE** | +2.6 | motivated by / inspired by / builds on / extends / 受…启发·借鉴·在…基础上 |
| **OWN** | +2.2 | we propose / in this work / our method / 本文提出·我们的目标 |
| **USE** | +1.6 | we adopt / based on / following / 我们采用·基于 |
| **FUTURE** | +1.0 | future work / we leave / 未来工作 |
| **BASELINE** | +1.4 | baseline / compared with / **unlike** / in contrast to / 基线·对比·不同于 |
| **RESOURCE** | **−2.2** | dataset / toolbox / library / codebase / we evaluate on / 数据集·工具包·代码库 |

**批量折扣**（一句里塞了多少篇）

| 同句引用数 | 系数 |
|---|---|
| 1（独占一句） | ×1.15 |
| 2 | ×0.85 |
| 3 | ×0.60 |
| ≥4（批量罗列） | **×0.35** |

**汇总**：`分数 = 最强一次×1.0 + 其余前两次×0.55 + min(出现次数,6)×0.35`，摘要与引言双现 +1.0，跨 ≥3 章节 +0.8。

**排除规则**（命中即标"疑似次要"）：未出现在摘要/引言/相关工作且无动机线索；全部出现在批量罗列句中；主要为数据集/工具引用；全文仅 1 次且位于实验章节。

**把握程度**：≥1 条强证据(GAP/INSPIRE) 且跨 ≥2 章节 且元数据完整 → **高**；否则视情况为**中/低**。

## 五、已知边界（重要，别高估这套东西）

1. **分数是检索排序，不是概率**。只在**同一篇论文内部**可比，跨论文比无意义。第 1 名与第 4 名差距不足 2 倍时，排序基本不可信，必须人工看。
2. **中文论文的线索词覆盖弱于英文**。已加入中文线索，但**未在真实中文语料上验证精度**，中文稿件请务必人工复核。
3. **作者年制引用**若参考文献条目解析不出作者名，对齐会失败 → 用 `--refs` 提供 BibTeX。
4. **本质盲区：隐性启发检不出**。如果本文从头到尾没点名某篇文献（但确实受它影响），任何基于全文引用上下文的方法都无能为力。要覆盖这种情况必须引入外部共引数据（OpenAlex / S2），那时已不是"读一篇论文"的问题了。
5. **扫描件 / 双栏 / 上标引用标记**会导致抽取退化，表现是"未识别到引言章节""引用上下文数为 0"。

## 五之二、真实论文实测（IEEE TPAMI 双栏稿）

测试对象：Maroudis et al., *Weight Importance Is Not Enough: Neural Expressiveness for Model Compression*，
TPAMI 2026，15 页 / 77 篇参考文献 / 211 条引用上下文。Ground truth 由引言明示：
"**Inspired by the concepts of "Information Plasticity" [1] and the "Lottery Ticket Hypothesis" (LTH) [13]**…"。

**结果**：[13] 第 3、[1] 第 4、[45]（*Rethinking the Value of Network Pruning*，揭示 importance 路线的局限）第 10。
三篇均被召回，完整分析见 `NEXP_核心启发文献.md`。

**暴露并修复的四个工程缺陷**（都是真实排版才会触发的）：

| # | 缺陷 | 后果 | 修复 |
|---|---|---|---|
| 1 | 罗马数字标题 `I. INTRODUCTION` 未识别 | 123 条上下文落入 `(正文开头)`，**Method 章节权重反超 Introduction**，基线文献被顶上榜首 | 新增 `HEADING_NUM_RE` + `looks_like_heading()`（要求全大写且 ≤12 词，排除图注） |
| 2 | 按 PDF 行切句，双栏换行 ≠ 句末 | `[45]` 句子被截断，"limitations / criticize" 全部线索丢失，**掉到第 43 名** | blocks 按栏排序 + **合并行还原段落**（含连字符），参考区保持行级按 `[n]` 切条 |
| 3 | 段落合并吞掉 `REFERENCES` 标题行 | 参考文献解析归零（0/77） | 合并时排除命中 `REF_SECTION_RE` 的行 |
| 4 | 线索正则尾部 `\b` 使**复数失效**（`\blimitation\b` 匹配不到 `limitations`） | 即使修了 #2，[45] 仍无线索 | 全部词干显式携带屈折后缀（`limitations?`、`shortcomings?`、`ignore[sd]?`、`(?:uses\|adopts\|…)`） |
| 5 | 段落合并缺"**句末才断**"判据 | 单栏文档每行就是完整句子 → 一路串成巨型单元，正文与参考文献混在一起，合成样本只剩 1 篇参考文献 | 仅当**前一行不以** `[.!?。！？;；:：]` 结尾时才合并（标准去换行规则） |
| 6 | REFERENCES 定位假设"在文档后 55%"；分栏用块**中心点**判栏 | 参考文献靠前的稿子直接漏；超长行溢出页宽时中心点落右半边，被误判成右栏排到最后，**丢掉整段正文** | 全文扫描取**最后一次**出现；判栏改用**左边缘** `x0 < width/2` |

**最重要的教训**：本例 Top1 与 Top4 分差只有 **3%**，远低于下面第六条清单里要求的"2 倍"阈值。
按那份清单，**这一篇的排序本就不可直接采信**——这与事实一致：得分最高的两篇
（[35] Pruning Filters、[48] Importance Estimation）恰恰是本文**要与之划清界限的那一类方法的代表**，
属于论证对象而非思想来源。规则分数衡量的是"在争议语境中被提到的密度"，不等于"启发了本文"。

## 五之三、第二次实测（ICLR 2026 单栏 LaTeX 稿，DiffLift / arXiv:2608.01160）

验证对象已知答案：引言明写"To date, differentiable lifting has only been explored in the context of
cell complexes (Battiloro et al., 2024)"，且 DCM 是全文唯一的可微提升基线。

修复后管线把 **Battiloro 2024 排到榜首（15.68，把握=高）**，Hajij 2022 紧随其后（13.24），与人工判定一致。

- **出现次数与启发强度可以反向**：全篇引用最多的是 Bodnar 2021a（12 次，评估骨干网络+静态
  lifting 基线），真正的种子只被引用 4 次。
- Top1/Top2 = **1.18 倍**，再次低于"2 倍"阈值；本例顺序靠逐字证据（"To date …only been
  explored"、"a differentiable lifting baseline"）定，不靠分数。

本轮又暴露 **8 个缺陷**（全部无法在合成样本上复现）：

| # | 缺陷 | 后果 | 修复 |
|---|---|---|---|
| 7 | 书目表**无编号**（ICLR/ACL 作者列表式），解析器只认 `[n]` | **0 条参考文献，管线空转** | `AUTHSTART_RE` + `parse_refs_unnumbered()`：作者串开头 + 含年份 |
| 8 | 跨页重复**页眉**未过滤 | 参考区首条变成 "Published as …Jie Chen, …" | 统计跨页重复短行作为 boiler 剔除 |
| 9 | LaTeX **章节编号单独成行** | 方法章标题识别失败，整章上下文计入 BACKGROUND | 编号行与后行合并后再判标题 |
| 10 | 页码过滤写成"见数字就删"（修 #9 时引入） | 编号 "3" 被误删，退回失效态 | 判据收紧为页首/页尾位置或 == 当前页码 |
| 11 | **作者-年匹配**用字符串前缀比对 | 对 "Surname, Given" / "M. Zaheer, S. …" 全部失配，0 条上下文 | `build_ay_index()` 姓氏索引 + 年份约束 + 位置消歧 |
| 12 | 书目拆分用非贪婪 `^(.*?)\.\s` | 作者截到 "M"，题名退化成整条原文 | `split_bib_entry()`：作者区边界取"位置 ≥12 且非缩写句点" |
| 13 | 参考区结束判据误用 `looks_like_heading` | 表格列名 **"Model"** 命中关键词，77 条截断成 6 条 | 附录语义关键词 + "连续两条长且无年份" |
| 14 | GAP 字典缺 `to date` / `only been explored` | 标准空白陈述句 0 分，种子掉到第 5 名 | 词典增补（`to date`、`thus far`、`only been explored/studied/considered`、`restricted to`） |

**新增 `--appendix`**：越过参考区继续抽取附录文本，标注为 `APPENDIX（附录）`。
动机：IPR-MPNN 与本文**共用 differentiable k-subset sampling**，但整套比较只在附录 E.4，
默认管线（在 REFERENCES 处停）永久看不见这类竞争者。

## 六、人工校验清单（5 分钟）

- [ ] Top1 分数是否 ≥ 第 4 名的 2 倍？不是 → 排序不可信，逐条看证据包。
- [ ] 每条结论是否都有**逐字原文**？概括性的"证据"一律不算。
- [ ] 有没有"背景罗列（本句无动机线索）"却仍被选中的？有 → 剔除。
- [ ] "对比基线"角色是否真的支撑本文贡献定义？仅实验表格出现的数字对比不算。
- [ ] LLM 是否输出了 `insufficient: true`？是 → 看 `missing_information` 补材料，不要硬编。
